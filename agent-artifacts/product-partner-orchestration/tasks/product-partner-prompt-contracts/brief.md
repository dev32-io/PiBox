# Task Brief: Product-partner prompt contracts

## Contribution Goal

Implement and register always-loaded orchestrator and planning prompt contracts for constructive outcome recovery, upstream premise challenge, proportional discovery, bug and incident distinctions, and delegation restraint.

## Boundary — Included

- Orchestrator outcome framing and materiality-boundary behavior.
- Planning behavior for feature, change, bug, diagnostic, and incident entry points.
- Behavioral scenarios for solution fixation, product-foot-gun challenge, proportionality, diagnosis, and delegation economics.

## Required Work

- Update prompt contracts and authoritative prompt registrations.
- Preserve user decision ownership and ad-hoc work.
- Add observable behavioral scenario coverage.

## Integration Expectation

Integrates as the prompt-contracts unit independently; downstream contributions consume its stable prompt and scenario interfaces.

## Boundary — Excluded

- Runtime registry, child process coordination, explorer protocol implementation, and lifecycle migration.

## Interfaces and Dependencies

Consumes the product-partner-and-subagent-lifecycle specification and orchestration design; exposes prompt behavior scenarios for the final lifecycle regression.

## Constraints

- Use existing prompt registries and role contracts.
- Do not turn discovery into universal ceremony or silently decide consequential product scope.
