# Task Acceptance: Render independent Reports and canonical evidence

## Deliverables

- Give each story a dedicated report catalog and Markdown detail experience with findings, history, evidence, and bidirectional task links.

## Acceptance

- Reports are independently browsable and clearly identify scope and result
- Full report/evidence content loads only after selection
- Task links appear only when canonical scope identifies a task and work in both directions
- Local canonical images render inline while external images do not auto-load
- Missing evidence does not break report readability

## Boundary Proof

- DOM and network-policy tests exercise representative task/story/stage/final/E2E reports and every evidence state
